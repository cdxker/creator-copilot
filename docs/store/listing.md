## Product name

Creator Copilot

## Summary

Plan stronger public X content with creator-controlled page previews, AI drafts, and experiments.

## Detailed description

Creator Copilot is a planning sidebar for creators working on public X content.

Open it beside a public profile, post, or feed. Creator Copilot extracts a small visible context only after you ask, shows you exactly what it found, and waits for confirmation. You can create deterministic recommendations locally or, with a beta invite, send the confirmed context for AI analysis.

Use Creator Copilot to:

- turn a public post or profile premise into editable hooks, replies, and follow-ups;
- keep voice guidance, welcomed topics, and hard boundaries in one local creator profile;
- review every detected context before any AI request;
- copy drafts explicitly without automatic posting; and
- run one focused content experiment with simple check-ins.

Creator Copilot does not read X direct messages, run in the background across websites, publish posts, send replies, follow accounts, make purchases, or change account settings. AI recommendations are hypotheses based only on the context you choose to supply; review every draft before using it.

The extension can be used in local mode without AI. AI beta access is invite-gated and rate-limited.

## Single purpose

Creator Copilot helps a creator plan and draft public X content from creator-selected, visible public-page context.
